# ETHICS.md — Educational purpose and authorized use only

**A-Secure-Warning-Platform-From-Web-Attacks-Using-Machine-Learning** exists for **education, research, defense, and authorized testing**
— on systems you **own**, or for which you hold **explicit written authorization**
defining scope and limits. It is not a toolkit for breaking into systems you do
not control.

## The four rules

1. **Authorized targets only.** Run this software exclusively on systems you own
   or hold written permission to test, with defined scope and limits. This is the
   line between education and crime. Unauthorized access is prohibited and may
   violate the **Computer Fraud and Abuse Act (18 U.S.C. §1030)**, the **Wiretap
   Act (18 U.S.C. §2511)**, **EU Directive 2013/40/EU**, and local cybercrime law.

2. **Teach and defend, don't enable.** Everything here is written from the
   perspective of a tester or defender improving their own estate: *never a
   how-to break into a third party; always a how-to check your own.*

3. **Safety by default.** Prefer local labs (VMs, localhost services, disposable
   containers, devices you own). When anything — if ever — touches real scope,
   it must be explicitly authorized, documented, and time-boxed.

4. **Responsible disclosure.** If using this software surfaces a real
   vulnerability in a real owner's system, report it privately, allow a fix
   window, and publish only after remediation. Never weaponize.

## Ownership of responsibility

This project is provided **AS IS**, for educational and defensive purposes. The
maintainers assume no liability for misuse. You are solely responsible for your
actions — and this project exists so those actions are educational, authorized,
and defensible.
